# Syllabus: Interview Preparation
## Faculty Weight: 13% | 6h/week | Target: Crack HFT + Top Tech Interviews

> **Reference Resources:**
> - *Cracking the Coding Interview* — Gayle Laakmann McDowell
> - *System Design Interview* — Alex Xu (Volumes 1 & 2)
> - Pramp / Interviewing.io (mock platform)
> - Glassdoor, LeetCode Discuss (company-specific questions)
>
> **Weekly Cadence:** 2h behavioral + 2h technical mock + 2h research/application

---

## Phase 1: Foundation (Weeks 1–13) — Resume & Basics

### Week 1 — Self-Assessment & Goal Setting
- [ ] Audit current resume, LinkedIn, GitHub
- [ ] List all projects with technical details
- [ ] Identify top 3 weakest technical areas
- [ ] Create target company spreadsheet (10 companies, deadlines, contacts)
- **Deliverable:** Gap analysis document

### Week 2 — Resume Engineering
- [ ] Single-page resume format for tech/HFT
- [ ] Action verb + metric structure for bullet points
- [ ] Tailor resume for C++/systems roles specifically
- [ ] Review with 2 peers or mentors
- **Deliverable:** Polished resume (PDF + LaTeX source)

### Week 3 — GitHub Portfolio Setup
- [ ] Profile README with tech stack and interests
- [ ] Pin top repositories (current + planned projects)
- [ ] Ensure all repos have: README, build instructions, license
- [ ] Contribution graph — aim for daily streak
- **Deliverable:** Professional GitHub profile

### Week 4 — LinkedIn Optimization
- [ ] Headline: specific role target (e.g., "C++ Systems Engineer")
- [ ] Summary: 3 paragraphs (who, what, seeking)
- [ ] Connect with 20 engineers at target companies
- [ ] Follow target company pages for job alerts
- **Deliverable:** Optimized LinkedIn profile

### Weeks 5–6 — Behavioral Interview Framework
- [ ] STAR method: Situation, Task, Action, Result
- [ ] Prepare 8 stories covering: leadership, conflict, failure, teamwork, initiative, learning, deadline pressure, technical challenge
- [ ] Practice telling each story in 2 minutes
- [ ] Research company values for Tier 1-3 targets
- **Deliverable:** Behavioral story bank (8 stories, written out in STAR format)

### Weeks 7–8 — Technical Communication
- [ ] Practice thinking aloud while coding
- [ ] Explain a complex concept (e.g., memory ordering) in 3 minutes
- [ ] Whiteboard problem-solving technique: clarify → examples → approach → code → test
- [ ] Record yourself solving a problem, review for clarity
- **Deliverable:** 3 recorded self-mock sessions

### Weeks 9–10 — Company Research Deep Dive
- [ ] **Week 9:** Tier 1 research (Tower Research, iRage, IMC)
  - Interview process, rounds, typical questions
  - Company culture, team structure, tech stack
  - Glassdoor reviews, LinkedIn employee profiles
- [ ] **Week 10:** Tier 2-3 research (Morgan Stanley, Goldman, Google, NVIDIA)
  - Same research framework as above
  - Application timelines, referral contacts
- **Deliverable:** Company profiles document with interview intel

### Weeks 11–13 — Online Assessment Prep
- [ ] Timed OA practice: 3 problems in 90 minutes
- [ ] MCQ prep: OS concepts, networking, C++ language trivia
- [ ] Computer architecture MCQs (cache, pipelining, virtual memory)
- [ ] Practice on HackerRank, HackerEarth environments
- **Deliverable:** 5 full mock OAs completed

---

## Phase 2: Deepening (Weeks 14–26) — Mock Interviews Begin

### Weeks 14–15 — C++ Technical Interview Prep
- [ ] "Implement from scratch" questions:
  - `std::vector`, `std::string`, `std::unique_ptr`, `std::shared_ptr`
- [ ] Language trivia: virtual dispatch, object slicing, undefined behavior
- [ ] Memory layout questions: size of struct, alignment, padding
- [ ] Timed practice: implement + explain in 30 min
- **Deliverable:** Written solutions for 8 "implement from scratch" problems

### Weeks 16–17 — Systems Interview Prep
- [ ] OS questions: process vs thread, virtual memory, page faults
- [ ] Concurrency questions: deadlock conditions, race condition scenarios
- [ ] Networking: TCP 3-way handshake, TCP vs UDP, DNS resolution
- [ ] Linux: file descriptors, epoll vs select, signals
- **Deliverable:** Flashcard deck of 50 systems interview Q&As

### Weeks 18–19 — First Mock Interview Round
- [ ] 2 peer mock interviews (DSA focus)
- [ ] 2 peer mock interviews (C++ systems focus)
- [ ] Detailed feedback collection and weak area identification
- **Deliverable:** Mock interview feedback log

### Weeks 20–22 — Application Strategy
- [ ] **Week 20:** Prepare application materials for each Tier 1 company
- [ ] **Week 21:** Submit Tier 2-3 applications (Morgan Stanley, Goldman, Bloomberg)
  - These are "warm-up" interviews — apply early
- [ ] **Week 22:** Reach out to alumni/connections at target firms for referrals
- **Deliverable:** Applications submitted to Tier 2-3 companies

### Weeks 23–26 — Intermediate Mock Sessions
- [ ] 1 full mock interview per week (rotating: DSA → Systems → Behavioral → System Design)
- [ ] Post-mock analysis: what went wrong, what to review
- [ ] Start tracking: time-to-solution for different problem types
- **Deliverable:** 4 mock interviews completed with feedback logs

---

## Phase 3: Specialization (Weeks 27–39) — Intensive Interview Training

### Weeks 27–28 — HFT-Specific Interview Prep
- [ ] Market microstructure basics: order book, bid-ask spread, liquidity
- [ ] FIX protocol overview
- [ ] Latency optimization questions: "How would you reduce latency in X?"
- [ ] Probability and statistics basics (expected value, Bayes' theorem)
- **Deliverable:** HFT domain knowledge cheat sheet

### Weeks 29–30 — System Design Interview Mastery
- [ ] Practice the 45-min framework under time pressure
- [ ] 2 mock system design interviews per week
- [ ] Focus on: estimation → architecture → deep dive → tradeoffs
- **Deliverable:** 4 system design mocks completed

### Weeks 31–33 — Project Deep Dive Preparation
- [ ] For each portfolio project, prepare:
  - 2-minute overview
  - Technical deep dive (architecture, data flow, bottlenecks)
  - "What would you do differently?" answer
  - Performance metrics and benchmark results
- [ ] Practice getting grilled on implementation details
- **Deliverable:** Project presentation deck (talking points only, no slides)

### Weeks 34–36 — Full Interview Simulation
- [ ] Simulate a complete interview day:
  - Round 1: Online assessment (90 min)
  - Round 2: C++ systems (45 min)
  - Round 3: DSA coding (45 min)
  - Round 4: System design (45 min)
  - Round 5: Behavioral (30 min)
- [ ] Do this simulation 3 times (once per week)
- **Deliverable:** 3 full-day simulations completed with scoring

### Weeks 37–39 — Tier 1 Applications
- [ ] Submit applications to Tower Research, iRage, IMC, Graviton, WorldQuant
- [ ] Finalize referral requests
- [ ] Prepare company-specific question sets from Glassdoor/LC Discuss
- **Deliverable:** Tier 1 applications submitted

---

## Phase 4: Peak & Place (Weeks 40–52) — Active Interviewing

### Weeks 40–43 — Active Interview Period
- [ ] Continue 2 mock interviews per week alongside real interviews
- [ ] Post-interview debrief: what was asked, how you performed, what to improve
- [ ] Adjust study focus based on real interview feedback
- **Deliverable:** Interview log with company, round, questions, self-score

### Weeks 44–48 — Negotiation & Decision Prep
- [ ] Research compensation benchmarks for each company/role
- [ ] Prepare negotiation framework: base, bonus, signing, equity, benefits
- [ ] Practice salary negotiation conversations
- [ ] Evaluate offers holistically: growth, team, tech stack, compensation
- **Deliverable:** Compensation comparison spreadsheet

### Weeks 49–52 — Closing
- [ ] Final round interviews / on-sites
- [ ] Send thank-you notes to interviewers
- [ ] Make final decision with structured pros/cons analysis
- [ ] Celebrate 🎉
- **Deliverable:** Signed offer letter
